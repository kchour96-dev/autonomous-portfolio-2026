Market Impact

A significant security disclosure this cycle involves the 'Click2Shell' vulnerability chain in WordPress Core, now patched in version 7.1.1 as of September 17, 2026. This critical flaw allowed unauthenticated attackers to force a logged-in Administrator's browser to silently install a malicious theme and plugin. The vulnerability chain, which included a selector-injection flaw (changeset 63664) and a CSRF vulnerability in the Zita Elementor Site Library plugin due to missing nonce verification, could effectively hand over an entire website. While WordPress has addressed 11 fixes in this release, the sheer prevalence of WordPress installations means a substantial attack surface remains for sites not yet updated, posing an ongoing threat to digital infrastructure.
